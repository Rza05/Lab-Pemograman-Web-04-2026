# Kopi Senja

Halaman pemesanan menu Kedai Kopi Senja.
Dibuat dengan React (Vite) dan Tailwind CSS (CDN).

## Cara menjalankan
1. npm install
2. npm run dev
3. Buka alamat yang muncul di terminal (biasanya http://localhost:5173)

## Fitur
- Menampilkan 9 menu beserta harga
- Filter kategori (Kopi, Non-Kopi, Makanan)
- Lihat detail tiap menu
- Menu habis tidak bisa dipesan
- Jumlah dan total harga di Navbar dan Ringkasan
- Form nama dan nomor meja dengan validasi
